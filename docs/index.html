voloop

voloop 是一个面向电源控制器的 C 语言控制算法库， 目标是提供可复用、可测试、可移植的控制模块。

当前模块

  • PID 控制器
  • FOF 一阶滤波器
  • NCO 数控振荡器
  • PLL 锁相环
  • Buck 控制器

快速集成

如果使用 CMake，可以将 voloop 作为源码库加入工程：

add_subdirectory(voloop)

target_link_libraries(my_app PRIVATE voloop)

在 C 文件中包含头文件：

#include "voloop.h"
